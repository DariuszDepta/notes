# Fedora 35 solid desktop color

Fedora 35 has fascinating desktop background pictures.
But I am used to have a solid background color.
To set the solid background color for desktop, issue the following commands:

```shell
$ gsettings set org.gnome.desktop.background picture-uri ''
$ gsettings set org.gnome.desktop.background primary-color '#10199E'
```

Helpful list of web colors: https://en.wikipedia.org/wiki/Web_colors
